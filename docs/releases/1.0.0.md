# Bot 1.0.0

Bot gives Codex one fast, readable terminal interface. Install a release
binary, sign in with the official Codex client, and run `bot` in a project.
Bot keeps Codex credentials, configuration, and conversations with Codex.

The release supports Linux x86-64 and ARM64, macOS Intel and Apple silicon,
and Windows x86-64. The installers select a matching archive, check its
SHA-256 value, and install the binary without a Rust build. Each archive also
has a GitHub build attestation and license notices.

Bot 1.0.0 includes text and image input, streaming, reasoning and tool views,
approvals, models and effort levels, account and usage views, MCP servers,
skills, hooks, and native Codex conversation actions.

Grok is experimental. Claude and isolated multi-account profiles are not in
this release. See the [release status](../release-status.md) for limits and
planned work.
