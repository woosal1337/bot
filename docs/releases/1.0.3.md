# Bot 1.0.3

Bot 1.0.3 adds live Codex usage data, verified self-updates, and reliable Herdr
startup detection.

- The status area shows live context use and Codex account limits when the
  provider supplies them.
- `/usage` presents session context, token totals, and account usage in one
  view.
- `bot update --check` checks for a stable release without changing files.
- `bot update` downloads and verifies the correct release before it replaces
  the installed binary.
- Bot claims its Herdr pane before Codex starts, so Herdr can list Bot reliably
  after a new or resumed session opens.
- Provider adapters accept partial usage events without losing known values.

To update Bot 1.0.2 or an older release on macOS or Linux, close Bot and run:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://raw.githubusercontent.com/woosal1337/bot/main/scripts/install.sh | sh
```

To update on Windows, close Bot and run this command in PowerShell:

```powershell
irm https://raw.githubusercontent.com/woosal1337/bot/main/scripts/install.ps1 | iex
```

After you install Bot 1.0.3, later stable releases can use:

```sh
bot update --check
bot update
```

Restart active Bot sessions after an update. Run `bot --version` after the
restart. It must report `bot 1.0.3`.

This release includes binary archives for Linux x86-64 and ARM64, macOS Intel
and Apple silicon, and Windows x86-64. Each archive has a release checksum and
build provenance.
