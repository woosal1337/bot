# Bot 1.0.4

Bot 1.0.4 makes the version in the welcome screen match `bot --version`.

- The executable and welcome screen now use one workspace release version.
- A release test starts the compiled executable and compares its version with
  the version used by the TUI.
- The release workflow stops if the executable and TUI package versions differ.

Close active Bot sessions before the update, run `bot update`, and start Bot
again. Both version displays must report 1.0.4.
