# Bot 1.0.2

Bot 1.0.2 adds Herdr lifecycle reporting and clear turn outcome receipts.

- Bot reports its session identity and idle, working, and blocked states to Herdr.
- Completed, stopped, and failed turns use distinct persistent receipts.
- Resumed Codex conversations restore terminal receipts in transcript order.
- The installers replace an existing Bot binary atomically.
- Release assets include checksummed installer scripts.

To update on macOS or Linux, close Bot and run:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://raw.githubusercontent.com/woosal1337/bot/main/scripts/install.sh | sh
```

To update on Windows, close Bot and run this command in PowerShell:

```powershell
irm https://raw.githubusercontent.com/woosal1337/bot/main/scripts/install.ps1 | iex
```

Run `bot --version` after installation. It must report `bot 1.0.2`.

This release includes binary archives for Linux x86-64 and ARM64, macOS Intel
and Apple silicon, and Windows x86-64. Each installer checks the archive before
it replaces the installed binary.
