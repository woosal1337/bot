# Bot 1.0.1

Bot 1.0.1 improves resumed Codex conversations and model preferences.

- Resumed conversations open at the latest message.
- Active-writer conflicts give a clear recovery path.
- You can set a default model and effort level for each provider.

This release includes binary archives for Linux x86-64 and ARM64, macOS
Intel and Apple silicon, and Windows x86-64. The installers verify each
archive before installation.
