# Bot 1.0.5

Bot 1.0.5 improves Codex preferences, usage data, and live-turn controls.

- Bot saves each provider's default model, effort, and permission mode.
- New sessions apply the saved preferences. Resumed sessions keep their existing provider state.
- Codex usage shows the correct remaining percentage and a readable reset countdown.
- Bot separates live context use from cumulative session tokens.
- Codex `/btw` answers a side question without interrupting the active turn.
- Codex `send now` uses native turn steering and safely requeues a rejected message.
- Completed turns show `Task finished` in the transcript and notification.
- The macOS installer uses a portable SHA-256 check.

Close active Bot sessions before the update. Run `bot update`, then start Bot again.
Run `bot --version` to confirm version 1.0.5.
